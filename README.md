# Майя — помощница для Claude Code

Майя — озорная, смешная и бесконечно любопытная маленькая помощница. Она стоит над полем ввода в Claude
Code (приложение для компьютера, VS Code, мобильное приложение) и показывает, что сейчас делает Claude.

![Майя](art/idle.gif)

| Когда | Майя |
|---|---|
| начало сессии | машет: «Привет!» |
| вы отправили сообщение | подпрыгивает: «Ура, задание!» |
| Claude работает | «Майя думает…» |
| Claude ждёт ответа или разрешения | «Майя ждёт твоего ответа» |
| ошибка инструмента или сбой | «Ой!» |
| ответ готов | «Готово! Майя проверяет», потом отдыхает |
| долго ничего не происходит | время от времени оглядывается |

В приложении для компьютера Майя заменяет и стандартный индикатор ожидания Claude: пока идёт ответ, она
стоит там со своей подписью и шагом, который сейчас выполняется, а над полем ввода её на это время нет.

Майя говорит на языке, на котором вы пишете: английском, русском или иврите (на иврите подпись идёт справа
налево). Язык определяется по буквам вашего сообщения и запоминается до следующего чата.

Команда `/maya` прячет Майю и возвращает обратно. В терминале её не видно: там нельзя показать картинку.

## Установка

В строке ввода сессии Claude Code в терминале:

```
/plugin install maya --marketplace chekayufor/maya-pet
```

Из командной строки:

```bash
claude plugin install maya --marketplace chekayufor/maya-pet
```

В приложении для компьютера, где `/plugin` не работает: нажмите **+** рядом с полем ввода, затем **Plugins**,
**Add marketplace** с адресом `chekayufor/maya-pet`, затем **Add plugin**.

Сначала появится вопрос `Add marketplace?`: ответьте `y`, затем выберите область установки (Enter — для
пользователя).

Репозиторий публичный: установить мод может любой, вход в GitHub для этого не нужен.

## Что внутри

| Путь | Что это |
|---|---|
| `.claude-plugin/plugin.json` | Описание мода |
| `.claude-plugin/marketplace.json` | Делает репозиторий источником для установки |
| `hooks/register.tsx` | Логика: какие события какую анимацию включают, как Майя рисуется |
| `hooks/frames.ts` | Кадры анимаций: PNG-полосы 144×156, встроенные как base64 (сгенерировано) |
| `types/index.d.ts` | Типы состояния мода |
| `tests/maya.test.tsx` | Тесты (`claude plugin test .`) |
| `art/maya-spritesheet.png` | Исходный атлас: 8 × 11 кадров по 192×208 |
| `art/*.gif`, `art/motion-proof.png` | Превью |
| `tools/make_strips.py` | Пересобирает `hooks/frames.ts` из атласа |
| `tools/render_previews.py` | Пересобирает GIF-превью из атласа |

## Как изменить кадры

Нужны Python 3.9+ и Pillow 9.1+.

```bash
python tools/make_strips.py art/maya-spritesheet.png hooks/frames.ts 0.75 256
```

Приложение показывает встроенную картинку только в формате PNG и только как обычное изображение SVG (без
`isInteractive`), поэтому кадры собираются в PNG. Каждая анимация должна умещаться в 131 072 символа: скрипт
остановится, если полоса получится больше.
